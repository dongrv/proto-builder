# 交互体验优化：1.3.0-dev.1

本页功能包含在 [v1.3.0-dev.1 预发布版](https://github.com/dongrv/proto-builder/releases/tag/v1.3.0-dev.1)。稳定安装入口仍为 [v1.2.0](https://github.com/dongrv/proto-builder/releases/tag/v1.2.0)。

交互验收于 2026-10-29 完成。下载预发布版 Windows x86_64 EXE 后，可直接启动：

```powershell
.\proto-builder-1.3.0-dev.1-windows-x86_64.exe web
```

请使用 Release 附件中的 `SHA256SUMS` 核对发布文件。下文记录交互改进及其验收范围，Agent v2 增强另见 [JSON 请求](AGENT-REQUESTS.md) 和 [MCP 接入](MCP.md)。

## 本轮改进

- **选择范围更清楚**：已选 ID 常驻显示为可移除标签。输入尚未加入范围时，会阻止直接执行并提示处理，避免把搜索误当选择后意外全量编译。
- **预览与参数保持对应**：修改参数后，旧预览立即标记过期；将参数还原到原预览值后恢复有效。执行摘要展示当前范围、输出目标和覆盖策略。
- **检查与构建一致**：环境检查、预览和构建共用输出目录校验，提前指出目录重叠；关闭的输出目标不参与本次输出校验。
- **项目加载不丢状态**：重新加载同一项目保留当前编辑与结果；切换项目时，有未保存修改才提示确认。成功确认过的路径可折叠为摘要，日常选择协议更方便。
- **错误可以直接处理**：失败信息明确说明原因、文件是否改变和建议动作，保留原文件及行号。报告保存失败单独提示，不会把已写回生成物误报成未写回。
- **结果提供下一步入口**：完成后展示真实增删改数量，可打开协议文档、产物目录及备份目录；备份按原文件名浏览和导出，无需手动读取 `index.json`。导出不会原位覆盖项目文件。
- **说明更易读、易点**：扩大问号点击范围，提高重要文字的可读性，支持深浅配色和中英文切换。
- **CLI 帮助更明确**：参数按路径、筛选、生成、执行、输出分组，补充说明与示例。新增 `--no-protocol-config`，原 `--no-config` 保留兼容；两者都只关闭协议号配置生成，仍会读取 TOML。
- **键盘向导更顺手**：长路径支持光标移动、Home/End/Delete 和水平滚动；Ctrl+C 在各层统一取消。失败后停留在可滚动结果页，保留完整诊断、写回状态和报告位置，再返回修改。ID 目录复用扫描元数据，并支持手动添加 ID 或排除 glob。

## 验证结果

- UX 阶段的 58 项 Rust 测试通过；加入 Agent v2 后，整包 84 项 Rust 测试、58 个独立 EXE 场景、格式检查及 Clippy 严格检查通过。
- 浏览器在隔离项目中验证了未确认输入拦截、已选标签、预览失效与恢复、同项目重载保留、跨项目未保存确认、路径折叠、结构化错误、结果快捷入口和备份导出。
- 45 个测试协议中选择 7001、7002，实际编译 3 个协议（含公共协议），共享文档包含完整 33 个非 RPC 协议；重复编译没有文件变化。
- 导出的备份与覆盖前原文件逐字节一致。注入协议语法错误后，已有生成物的 SHA256 保持不变；模拟日志保存失败时，页面正确显示生成物已写回，并单独提示报告问题。
- 已验证深浅配色与英文切换。键盘向导的编辑、取消和错误文本通过状态机测试，尚未完成真实终端全流程人工验收。

所有编译和错误注入均使用隔离测试项目，未改写业务工程产物。单个备份超过 128 MB 时，该任务的结果快捷入口会禁用，可复制备份目录路径手动查看。
