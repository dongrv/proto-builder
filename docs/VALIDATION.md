## 原工具字节基准

原 BAT/Python 文件未修改。旧工具只在独立内部目录运行，用于采样；新程序运行不依赖这些脚本。

| 场景 | 业务服相同文件 | 计算服相同文件 | proto 树相同文件 | 缺失 / 多余 / 字节差异 |
| --- | ---: | ---: | ---: | --- |
| 全量 | 862 | 342 | 995 | 0 / 0 / 0 |
| 旧 ID 7034 | 21 | 11 | 995 | 0 / 0 / 0 |
| 旧 ID 6034 | 21 | 13 | 995 | 0 / 0 / 0 |

proto 树计数包含原始协议源文件和原目录中保留的文件，以及新生成的文档和 JSON；不是声称生成了 995 个新文件。全量业务服含 859 个 Go 文件及 3 个部署后的 ProtoConfig.json。配置 JSON 的字节对比包含 CRLF、顺序、缩进和末尾换行行为。

release 构建在本机、内置工具链缓存已准备、8 个工作线程、SVN 更新关闭的条件下，对 693 个 proto 执行 633 次工具命令、465 个任务组，用时约 28 秒；第二次构建 1505 项输出均未变。该数值是单机样本，不包含网络 SVN 等待，也不代表所有机器的性能承诺。
